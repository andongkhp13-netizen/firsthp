스마트 PDF 통합 관리 시스템 사무용 v2.0 (검증완료)

누구나 안전하고 쉽게 사용하는 웹 기반 통합 PDF 솔루션

보안 안심: 모든 파일은 외부 서버 전송 없이 브라우저 내에서만 안전하게 처리됩니다.

PDF 병합 사용 방법

1. 병합할 여러 PDF 파일을 아래 박스에 끌어다 놓거나 [파일 선택]으로 추가하세요.

2. 목록의 핸들()을 드래그하거나 위/아래 버튼으로 합칠 순서를 조정하세요.

3. 각 파일별로 필요한 페이지 범위(예: 1-3, 5)를 지정하거나 [페이지 선택] 모달을 통해 골라낼 수 있습니다.

4. 하단의 [PDF 하나로 병합하기] 버튼을 누르면 설정된 순서대로 하나의 PDF 파일이 생성됩니다.

참고

각 파일별로 원하시는 특정 페이지(예: 1-3, 5)만 선택하여 필요한 부분만 하나로 통합할 수 있습니다.

PDF 분할 사용 방법

1. 분할하려는 PDF 파일 1개를 업로드하세요.

2. 원하시는 페이지 범위를 1-3, 5, 8-10 형태로 입력하세요.

3. 입력한 범위별로 각각 별도의 PDF 파일로 분할되어 (2개 이상일 경우 ZIP 압축) 다운로드됩니다.

분할할 PDF 파일을 여기에 끌어다 놓으세요

또는 클릭하여 내 PC에서 1개의 PDF를 선택하세요

파일 선택하기

파일명.pdf

총 0페이지 | 0 MB

입력 예시 설명:

  • 1-3, 5, 8-10 : 총 3개 파일 생성 (1~3p / 5p / 8~10p)
  • 1, 2, 3 : 1p, 2p, 3p 각각 개별 파일 생성
범위 입력 무시됨

페이지 추출 및 회전 사용 방법

1. 작업할 PDF 파일을 업로드하면 전체 페이지의 미리보기가 표시됩니다.

2. 원하시는 페이지를 클릭하거나, 상단 페이지 범위 입력(`1-3, 5`)을 이용해 빠르게 선택할 수 있습니다.

3. 상단의 [일괄 회전] 버튼으로 선택한 페이지들을 한 번에 회전하거나, 각 카드별 [회전] 버튼을 이용할 수 있습니다.

4. [선택한 페이지 저장]을 누르면 선택한 페이지들만 회전 상태가 반영되어 새 PDF로 저장됩니다.
